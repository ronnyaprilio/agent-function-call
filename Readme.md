# Agent Function Call Simulation

Production-ready starter app for simulating agent tool/function calls.

## Stack
- Next.js + TypeScript
- Django + Django REST Framework
- MongoDB + MongoEngine
- Docker Compose

## Features
- Session creation
- Chat-like simulation
- Tool/function call timeline
- MongoDB persistence
- Health endpoint
- Typed frontend API

## Run locally with Docker

```bash
docker compose up --build
